Activity Organizer 4 adds reusable app/window sessions to the GNOME Activities
overview, plus visible controls for changing custom-group membership.

- Expand a group and use a window's **Move ▾** menu to remove it or move it to
  another group. App-stack windows have a **Group ▾** menu.
- Automatic group saves survive closing apps, logout, and reboot. Save a
  separate version from the group's **⋯** menu.
- Reopen a saved version to launch fresh app windows into that group. Existing
  group members count toward the saved window totals.
- Manage saved versions and automatic saving in preferences.

For GNOME Shell 50. Install the `.shell-extension.zip` asset with
`gnome-extensions install --force PATH`, then log out and back in.

Restoration opens fresh app windows; app contents and internal tabs are managed
by the apps. Some applications cannot open additional windows. GNOME Extensions
submission/approval is separate from this GitHub release.
